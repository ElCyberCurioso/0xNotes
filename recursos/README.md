# Recursos

## Introducción

Colección de recursos útiles para ciberseguridad: cheatsheets de referencia rápida, links a plataformas y documentación externa, y guías de certificaciones profesionales.

## Contenido

### [Cheatsheets](cheatsheets.md)
Comandos y payloads de referencia rápida para uso en CTFs y pentesting:
- Reverse shells (Bash, Python, PHP, Netcat, PowerShell)
- Transferencia de archivos
- SQL Injection básico
- Nmap
- Privilege Escalation

### [Links Útiles](links.md)
Recopilación de recursos externos organizados por categoría:
- Plataformas de práctica (HTB, THM, VulnHub...)
- Documentación de referencia (OWASP, HackTricks, GTFOBins...)
- Comunidades y canales de YouTube
- Libros recomendados

### [Certificaciones](certificaciones.md)
Guía de certificaciones de ciberseguridad con costos, nivel y roadmap recomendado:
- Entry level: eJPT, Security+
- Intermediate: OSCP, PNPT, CEH
- Advanced: OSEP, OSWE, OSCE
- Red Team, Cloud y Blue Team
